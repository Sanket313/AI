from heapq import heappush, heappop

start = (1, 2, 3, 4, 0, 5, 7, 8, 6)
goal  = (1, 2, 3, 4, 5, 6, 7, 8, 0)

def h(s):
    return sum(s[i] != 0 and s[i] != goal[i] for i in range(9))

q = [(h(start), 0, start)]
best = {start: 0}

while q:
    f, g, s = heappop(q)

    if s == goal:
        print("Goal Reached:", s)
        break

    if g != best[s]:
        continue

    z = s.index(0)
    moves = [-3, 3, -1, 1]

    for d in moves:
        n = z + d
        if not (0 <= n < 9):
            continue
        if d == -1 and z % 3 == 0:
            continue
        if d == 1 and z % 3 == 2:
            continue

        t = list(s)
        t[z], t[n] = t[n], t[z]
        t = tuple(t)
        ng = g + 1

        if ng < best.get(t, 999):
            best[t] = ng
            heappush(q, (ng + h(t), ng, t))
else:
    print("No solution found")

Practical 3: A* Search for 8-Puzzle

Aim: To solve the 8-Puzzle problem using A* search.

Logic: A* selects a state using f(n) = g(n) + h(n). Here g is the number of moves so far and h is the number of misplaced numbered tiles.

Algorithm
1.	Set the initial state and goal state.
2.	Insert the initial state into a priority queue.
3.	Remove the state with the smallest f value.
4.	If it is the goal, display it and stop.
5.	Find the blank tile and generate legal moves.
6.	For each new state, calculate g + h and insert it into the queue.
7.	Repeat until the goal is found or the queue is empty.

Pseudocode
START
SET start and goal
INSERT start into priority queue with f = g + h
WHILE queue is not empty
    REMOVE state with lowest f
    IF state equals goal
        PRINT Goal Found
        STOP
    GENERATE legal next states
    CALCULATE f = g + h for each state
    INSERT new states
END WHILE
STOP
