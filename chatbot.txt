import re

rules = [
    (r"hello|hi|hey", "Hello! How can I help you?"),
    (r"how are you", "I am fine!"),
    (r"my name is (.+)", "Nice to meet you!"),
    (r"your name", "I am a Python Chatbot."),
    (r"happy|good", "That's great!"),
    (r"sad|unhappy", "I am sorry to hear that.")
]

while True:
    msg = input("You: ").lower()

    if msg in ["bye", "exit", "quit"]:
        print("Bot: Goodbye!")
        break

    found = False

    for pattern, response in rules:
        if re.search(pattern, msg):
            print("Bot:", response)
            found = True
            break

    if not found:
        print("Bot: Tell me more.")
Practical 8: Simple Rule-Based Chatbot

Aim: To develop a simple chatbot using Python.
Logic: The chatbot takes a message from the user and checks it using IF-ELIF conditions. It displays a predefined response for a matching message.

Algorithm
1.	Start the program.
2.	Ask the user to enter a message.
3.	Convert the message to lowercase.
4.	Check the message using IF-ELIF conditions.
5.	Display the matching response.
6.	If the message is bye, stop; otherwise repeat.

Pseudocode
START
REPEAT
    INPUT message
    IF message is hello
        PRINT greeting
    ELSE IF message is how are you
        PRINT status
    ELSE IF message is bye
        PRINT goodbye
        STOP
    ELSE
        PRINT don't understand
UNTIL bye
STOP
