def win(b, p):
    w = [(0,1,2),(3,4,5),(6,7,8),
         (0,3,6),(1,4,7),(2,5,8),
         (0,4,8),(2,4,6)]

    for a,c,d in w:
        if b[a] == b[c] == b[d] == p:
            return True
    return False


def minimax(b, ai):
    if win(b, "X"):
        return 1
    if win(b, "O"):
        return -1
    if " " not in b:
        return 0

    scores = []
    for i in range(9):
        if b[i] == " ":
            b[i] = "X" if ai else "O"
            scores.append(minimax(b, not ai))
            b[i] = " "

    return max(scores) if ai else min(scores)

Practical 7: Minimax Algorithm

Aim: To implement the Minimax algorithm for game playing.
Logic: MAX tries to get the highest value and MIN tries to get the lowest value. The algorithm evaluates leaf values and returns the best value at each level.

Algorithm
1.	Create a game tree with leaf values.
2.	If the current node is a leaf, return its value.
3.	At a MAX node, return the maximum of the child values.
4.	At a MIN node, return the minimum of the child values.
5.	Continue until the root value is found.
6.	Display the best value.

Pseudocode
FUNCTION MINIMAX(depth, index, player)
    IF depth is maximum
        RETURN leaf value
    IF player is MAX
        RETURN maximum of child results
    ELSE
        RETURN minimum of child results
