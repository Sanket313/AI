A = input("Room A: ")
B = input("Room B: ")

location = "A"

while True:
    if location == "A":
        if A == "Dirty":
            print("Suck A")
            A = "Clean"
        else:
            print("Move Right")
            location = "B"

    else:
        if B == "Dirty":
            print("Suck B")
            B = "Clean"
        else:
            print("Move Left")
            location = "A"

    if A == "Clean" and B == "Clean":
        print("Both rooms are clean")
        break
Practical 1: Simple Reflex Agent

Aim: To implement a Simple Reflex Agent that cleans two rooms.
Logic: The agent checks each room. If a room is dirty, it cleans it. The action depends on the current condition.

Algorithm
1.	Start.
2.	Take the condition of Room A and Room B.
3.	If Room A is dirty, clean it.
4.	If Room B is dirty, clean it.
5.	Display both room conditions.
6.	Stop.

Pseudocode
START
INPUT A, B
IF A is Dirty
    Clean A
END IF
IF B is Dirty
    Clean B
END IF
DISPLAY A and B
STOP
